Document numbering

New quotes and live invoices use these next numbers. Existing references stay unchanged. Test invoices use a separate TEST reference. Numbers can only move forward.

Office network access

Staff must use an approved computer connected to an approved network. Administrators can sign in from any network, including mobile. Individual remote permissions still require an approved staff computer.

Register the office connection while you are there, then enable the restriction. If the office public IP changes, an administrator can update it.

Remote access permissions

These permissions allow a staff member to connect outside the office network. Their existing account permissions still apply. Times use Nassau local time.

Discount approvals

Only administrators can enter quote or invoice discounts. To approve a standing customer discount, open their customer profile and use Approved customer discount. Staff can use that saved rate; other discounts need an administrator to save the draft.
